Each window runs BOTH strategies independently on the same auto-detected expiry-rollover window — a PE ("put") diagonal and a CE ("call") diagonal, each with its own strikes, triggers, and entries. PE's and CE's own realized figures are the primary numbers here and are never summed into one headline result; a muted "Combined (PE+CE)" line/column is shown purely as a what-if reference for running both together. Every chart also plots what happens after a window's own exit, dashed and muted, as a "what if held to actual settlement" reference — it was never realized. Every price is a real 5-min-candle LTP from option_chain_5m, backfilled from live Upstox where local capture had a gap. Simulation/research only — not open trades, and not a large enough sample to draw a conclusion from.
