Each window is a fully independent position (own entry, own P&L) — a new window begins on the first trading day whose own expiry-triplet resolution differs from the current one, and this window's position exits right then (not at its own near leg's actual settlement, which can land after the next window has already begun). Every chart also plots what happens after that exit, dashed and muted, purely as a "what if held to actual settlement" reference — it was never realized. Every price is a real 5-min-candle LTP from option_chain_5m, backfilled from live Upstox where local capture had a gap, and persisted so re-runs don't re-fetch. Simulation/research only — not open trades, and not a large enough sample to draw a conclusion from.
